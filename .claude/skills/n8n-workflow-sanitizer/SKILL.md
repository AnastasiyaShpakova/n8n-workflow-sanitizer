# Скилл n8n Workflow Sanitizer

Этот скилл предназначен для работы с локальным инструментом очистки JSON-файлов n8n от секретов перед их публикацией.

## 🎯 Назначение проекта
Инструмент выполняет статический анализ экспортированных workflow n8n, автоматически маскирует распознанные секреты (API-ключи, токены, email) и формирует отчет о рисках, требующих ручной проверки (например, `webhookId`).

## 📁 Структура проекта
- `app.py`: Основное приложение на Flask, логика маскирования и верификации целостности.
- `templates/index.html`: Одностраничный веб-интерфейс на русском языке.
- `tests.py`, `tests_detailed.py`, `test_webhook.py`: Набор автоматических тестов.
- `README.md`: Инструкции по установке и использованию.
- `REQUIREMENTS.md`: Спецификация требований и критерии приемки MVP.
- `uploads/`: Папка для временного хранения обработанных файлов и отчетов.

## 🚀 Локальный запуск
1. Установка зависимостей: `python -m pip install Flask==3.1.3`
2. Запуск приложения: `python app.py`
3. Доступ в браузере: `http://127.0.0.1:5000`

## 🛠 Работа с кодом и изменения
- **Безопасное изменение:** При изменении логики маскирования в `app.py` обязательно проверять функцию `verify_sanitization`, чтобы изменения не нарушили структуру JSON (количество нод, соединения, выражения).
- **Диагностика:** Используйте логи Flask в терминале для отслеживания ошибок обработки файлов.

## 🧪 Тестирование
Запуск всех тестов из корневой папки:
```bash
python -m py_compile app.py
python tests.py
python tests_detailed.py
python test_webhook.py
```
*Важно:* Успешный проход тестов подтверждает корректность маскирования базовых паттернов и сохранность структуры, но не гарантирует 100% очистки всех секретов.

## 📝 Документация и публикация
- **Обновление README:** При добавлении новых паттернов маскирования или изменении требований обновляйте разделы "Возможности" и "Тестирование".
- **Подготовка к GitHub:** 
    - Проверьте, что в репозиторий не попадают реальные workflow с секретами.
    - Убедитесь, что в отчетах и логах не выводятся реальные значения секретов (используйте `***` или заглушки).
    - Проверьте актуальность раздела "Статус проекта".

## 🔒 Специфика безопасности
- **webhookId:** Инструмент намеренно сохраняет `webhookId` для совместимости импорта. Это отмечается в отчете как риск. **Файл с нерешенными рисками нельзя считать готовым к публикации.**
- **Ручная проверка:** Автоматическая очистка является первым этапом. Окончательное решение о безопасности принимает пользователь после анализа `report_<timestamp>.md`.
- **Секреты:** Никогда не выводите реальные найденные секреты в консоль или файлы отчетов.
